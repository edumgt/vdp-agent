# 법인 기장 PDF 생성 모듈 — 요구사항/범위 정의 (v2.0)
작성일: 2026-07-07

## 1) 목표
법인의 회계 데이터(계정과목/분개/증빙/세금계산서/유형자산)를 기반으로 표준 기장 문서를 PDF로 생성하고,
ML/DL 파이프라인(OCR, 자동분류, 이상탐지, 예측)으로 기장 업무를 보조한다.
추가로 OpenDART 공시 데이터를 수집해 동일한 PDF 템플릿으로 재현하는 기능을 제공한다.

## 2) 포함 범위
### 2-1. 기장 문서 생성(PDF)
- 재무제표(재무상태표/손익계산서)
- 총계정원장/분개장
- 세금계산서/증빙 정리표(매입·매출, 수출비중 포함)
- 월간/연간 결산보고서(ML 분석 요약 포함)
- 기업 대시보드(제조원가명세서/유형자산 목록/수출비중 포함)

### 2-2. ML/DL 파이프라인
- 영수증/세금계산서 이미지 OCR + 정형 필드 추출(사업자번호/금액/일자/거래처)
- 계정과목 자동분류(거래 적요 텍스트 → 계정과목 예측 + 신뢰도)
- 이상거래/오분류 탐지(계정별 금액 이상치)
- 현금흐름/매출 예측(월별 시계열 기반)

### 2-3. OpenDART 연동
- 회사명 검색 → corp_code 조회
- 재무제표(전체) 수집 → 내부 재무상태표/손익계산서 템플릿으로 재현(PDF)
- API 키 미보유 시 fixture(실제 공개 데이터 축약본)로 동일 인터페이스 동작

### 2-4. 관리 기능
- 회사/계정과목/분개/증빙/보고서 CRUD 및 상태 조회 (Admin 콘솔)
- 법인 담당자용 증빙 업로드/보고서 다운로드 포털 (Client)

## 3) 제외 범위(2차 확장)
- 실시간 전자세금계산서 국세청 연동(홈택스 API)
- 다중 법인/연결회계(연결재무제표)
- 완전한 회계감사/내부통제(SOX) 대응
- LayoutLM/Donut 기반 문서이해, KoBERT 파인튜닝 분류기, LSTM/Prophet 등 고급 딥러닝 모델 (현재는 경량 baseline으로 대체, 고도화 경로는 `08_techstack_workflow.md` 참고)

> 변경관리: 제외 범위는 Change Request로 처리하며 일정/비용 재산정 후 2차 확장으로 진행한다.

## 4) 수용 기준(검수)
- 모든 분개는 차변/대변 합계가 일치해야 한다(API 단에서 검증).
- 생성된 PDF는 지정 폰트를 임베딩하며 페이지/표/차트가 깨지지 않아야 한다.
- ML 분류/이상탐지/예측 결과는 모델 버전과 함께 기록되어 추적 가능해야 한다(`ml_classifications`, `ml_anomalies`, `ml_forecasts`).
- DART 연동은 API 키 유무와 무관하게 동일한 응답 스키마로 동작해야 한다(fixture 자동 대체).
- 동일 입력(버전 동일)으로 재생성 시 PDF 페이지 구성이 재현 가능해야 한다.
